# 单链路 CIR 拟合测距：论文初稿结果

本报告基于 recordings(4).zip 的真实采集数据。所有图表都由随包代码生成；没有使用合成测量值，没有事后删除高误差距离，没有把负预测裁成零。

## 数据与评估边界

- 距离：1、2、3、4、6、9、12、15 m。每个距离有 A/B 两次采集，共 16 组，各约 120 秒。
- 643 个成功 FTM 会话中，638 个可提取有效同帧 CIR；覆盖率 99.22%。638 个会话包含 18,625 对有效同帧 FTM/CSI。A 组 318 个、B 组 320 个。
- 原始 FTM 与各模型均在同一批可用 CIR 会话上比较；另外 5 个会话的剔除原因保存在 selection.json。99.22% 是以已成功的 FTM 会话为分母的特征覆盖率，不是总体测距成功率。
- A 组用于训练；B 组用于选择正则化强度，同时展示验证性能。B 组不是独立最终测试集。未将相邻会话随机混合后分成训练/测试。
- 每组采集的训练总权重相同；特征均值、标准差只用 A 组计算。正则化候选为 1、10、100，按 B 组每次采集等权的 MAE 选择。
- 尚无 C 组独立最终测试；本报告是单链路测距结果，不是六 Anchor 的定位误差。
- 这些数据中没有已核实的六板 A1–A6 身份映射；A/B 是采集组名，不能等同于 Anchor 编号。

## 处理流程与模型

频域 CSI → 非 HT、20 MHz LLTF 的 IQ 解析及子载波映射 → 未观测频点的平滑 L1 重建 → 频域补零与 16 倍采样 IFFT → 相对 CIR 形状与频率选择性特征 → 回归。补零提供更密的时延采样，不增加原始信号带宽或物理分辨率。CIR 时间参考未做绝对传播时延校准，因此不把峰值索引直接换算成真实距离。

仅 CIR 模型使用 8 个特征：主峰邻域能量比例、早期能量比例、尾部能量比例、相对 RMS 时延扩展、归一化能量熵、相对前沿偏移、频谱平坦度和子载波幅度变异系数。后两项从同一 CSI 频谱计算。FTM＋CIR 模型另外使用原始 FTM 距离、帧 RTT 距离中位数、帧距离 MAD 和 FTM RSSI。

三种模型：FTM 线性校准；仅 CIR 特征的岭回归；FTM＋CIR 的残差岭回归。残差模型先预测真实距离减去原始 FTM 距离，再加回原始 FTM 距离。实际推理只使用测量特征，不输入真实距离、文件名、点号或板子坐标。

选定 alpha：FTM 线性=0，仅 CIR=100，FTM＋CIR=10。

## 主要结果

| 方法 | A 训练 MAE (m) | B 验证 MAE (m) | B RMSE (m) | B 中位绝对误差 (m) | B P90 (m) |
|---|---:|---:|---:|---:|---:|
| 原始 FTM | 5.142 | 9.777 | 13.742 | 6.450 | 19.395 |
| 固定输出训练均值 6.5 m | 4.123 | 4.134 | 4.731 | 4.000 | 8.500 |
| FTM 线性校准 | 0.799 | 4.630 | 8.422 | 1.561 | 10.324 |
| 仅 CIR 特征回归 | 1.985 | 4.516 | 5.863 | 4.115 | 9.301 |
| FTM＋CIR 残差修正 | 0.468 | 4.009 | 7.821 | 1.475 | 9.680 |

FTM＋CIR 在 B 组的 MAE 相对原始 FTM 下降 59.0%，但相对固定均值基线仅下降 3.0%。仅 CIR 模型的 B 组 MAE 高于该常数基线。因此当前证据不能支持纯 CIR 具备可靠的通用测距能力，也不能支持分米级泛化精度。

FTM＋CIR 的 A 组 MAE 为 0.468 m，这是训练回代误差。B 组 MAE 为 4.009 m、P90 为 9.680 m，显示跨采集组的性能退化。这种退化与模型过拟合、链路条件变化相容，但日志不足以确定唯一物理原因。

## 可直接写入初稿的结果段落

本研究在 1–15 m 范围内的八个离散距离进行单链路 LOS 测量，采集 A、B 两组数据，共获得 638 个具有有效同帧 CIR 特征的测距会话。模型仅使用 A 组进行拟合，使用 B 组选择正则化参数并评估验证性能。原始 FTM 在 B 组的 MAE 为 9.777 m，FTM 线性校准、仅 CIR 特征回归及 FTM＋CIR 残差修正后的 MAE 分别为 4.630 m、4.516 m 和 4.009 m。残差修正相对原始 FTM 的 MAE 降低约 59.0%，但与固定输出训练距离均值的基线相比改善有限；同时，其训练 MAE 为 0.468 m，明显低于验证 MAE。上述结果表明该方法在已采集条件下具有误差修正潜力，但跨采集组的泛化能力仍受限制，需要进一步开展独立测试与多 Anchor 验证。

## 拟合公式与复现

FTM 线性校准公式（距离单位 m）：`d_hat = 0.8272278238 * d_FTM -3.1287529012`。

CIR 直接回归：`d_hat = b + sum(beta_j * (f_j - mu_j) / sigma_j)`。FTM＋CIR 残差修正：`d_hat = d_FTM + b + sum(beta_j * (f_j - mu_j) / sigma_j)`。完整系数、标准化参数与模型元数据在 models/ 和 tables/model_coefficients.csv。

## 后续使用

根目录 models/ 对应本次八距离 A/B 拟合；不要与固件工具包根目录的旧三距离演示模型混用。模型仅在原测量链路上进行了上述验证，不应直接宣布可迁移至六块不同 Anchor。编号 A1–A6 后保持 20 MHz、信道 6、FTM offset=0，并记录每块 AP BSSID；在少量独立标定点检查各板偏差后，再冻结标定参数开展多 Anchor 测试。

本报告保留 20 个 FTM＋CIR 负距离预测和 85 个 OUT_OF_DOMAIN 标签的预测。质量标签仅用于诊断，未用于筛除样本；OUT_OF_DOMAIN 也不是经校准的失败概率。
