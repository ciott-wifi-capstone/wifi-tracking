# Archived prototypes

The folders here preserve the development snapshots and utilities separately from the main projects. Source scripts and firmware stay with their original variants because radio and host protocols changed over time. The folders under runtime_variants are overlays for the expandable multi-anchor host, rather than standalone applications. Some commands in the original notes refer to separately held recordings, models or old installation paths.

The main launch and testing steps are in the [project README](../README.md). The [source map](../SOURCE_MAP.md) records which ZIP supplied each snapshot. The early two-board snapshot retains the host and analysis utilities; partner firmware and unrelated reference materials were excluded.
